# 🌊 Sea Quake Alarm – Early Warning for Coastal Safety

## 📌 Project Overview

Sea Quake Alarm is an embedded system-based project designed to provide an early warning when seismic activity is detected. The system uses sensors to detect abnormal vibrations and activates an alarm/buzzer to provide an immediate warning.

The project was designed and simulated using Autodesk Tinkercad.

## 🎯 Objectives

- Detect seismic activity using sensors.
- Provide an immediate warning through an alarm/buzzer.
- Improve awareness and response during possible coastal earthquake events.
- Gain practical knowledge of embedded systems, sensor interfacing, and microcontroller programming.

## 🛠️ Technologies Used

- Arduino
- Embedded Systems
- C/C++
- Sensor Interfacing
- Autodesk Tinkercad
- Buzzer/Alarm

## ⚙️ Working Principle

1. The sensor monitors for abnormal vibrations.
2. The microcontroller processes the sensor readings.
3. When the detected value exceeds the defined threshold, the system activates the buzzer.
4. The buzzer provides an immediate warning.
